# img2bash

I wrote this Python script for the sake of making my life easier. `one-color-per-pixel.py` was the original version I wrote, but I noticed that the Xyric logo was a full gradient;
I wrote `one-color-per-row.py` as a modified version of `one-color-per-pixel.py` which only generates one color for an entire row based on the first pixel of a row.

Feel free to use this script however you want!
